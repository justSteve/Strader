Steve uses LuxAlgo Price Action Concepts order blocks as the primary targeting tool for butterfly center strikes. Mancini levels define the range and major pivots; PAC order blocks give the precise price target within that range.

**Why:** Screen-time pattern recognition — Steve reads the order block placement to identify where price is likely to gravitate. On 2026-05-20, with ES at 7,450 and Mancini's range top, Steve targeted 7,405 SPX based on a PAC order block, not the nearest Mancini level (7,402).

**How to apply:** When discussing butterfly strike selection, ask about or reference PAC order blocks as the centering mechanism. Mancini levels frame the trade (range support/resistance, bull/bear case); PAC order blocks pick the strike.
